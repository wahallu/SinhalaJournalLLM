How to use

  1. Highlight a sentence or paragraph in the document.
  2. Press the refresh button next to Selection above.
  3. Pick a tool and press its action button.
  4. Use Replace Selection to swap the highlighted text, or Insert to drop the result in at the cursor.

Testing a local backend

Apps Script's servers can't reach a backend running on your own computer (http://localhost:8000) directly.

Use a tunnel like ngrok to get a public URL, then paste it into API Base URL above:

ngrok http 8000
